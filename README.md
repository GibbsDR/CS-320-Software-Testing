Reflection
How can I ensure that my code, program, or software is functional and secure?

I ensure that my software is functional and secure by integrating testing directly into the development process. Writing unit tests alongside code allows me to validate both expected behavior and edge cases. By testing invalid inputs, null values, and boundary conditions, I reduce vulnerabilities and prevent unexpected system behavior. Exception handling and input validation further strengthen reliability and security.

How do I interpret user needs and incorporate them into a program?

I interpret user needs by carefully reviewing requirements and translating them into measurable constraints within the code. For example, when the requirements specified character limits and unique identifiers, I implemented validation logic within constructors and verified those constraints through unit testing. Breaking requirements into smaller, testable components ensures that user expectations are accurately implemented and verified.

How do I approach designing software?

I approach software design by first identifying requirements and defining clear responsibilities for each class. I design objects to enforce their own validation rules and use service classes to manage business logic. I also consider how the code will be tested during design, ensuring that components are modular and testable. This structured and disciplined approach promotes maintainability, clarity, and long-term quality.
